Umbra — лаунчер и клиент для Minecraft: Java Edition. Эта страница описывает, какие данные использует приложение и куда оно обращается.

Что хранится на компьютере

Профили, настройки, моды, миры, резервные копии и игровые логи хранятся локально. Лаунчер не отправляет миры и логи разработчику без твоего действия.

Umbra Ассистент

Локальная диагностика читает журналы выбранного профиля на твоём компьютере. При создании профиля запросы к Mojang и Modrinth нужны для получения версий и файлов, выбранных в плане. Облачный ассистент готовится к запуску.

Вход через Microsoft

Гостевой режим позволяет готовить профили и менять настройки. Для запуска игры Umbra требует вход через Microsoft и проверяет доступ аккаунта к Minecraft: Java Edition. Umbra зарегистрирована в Microsoft Entra и готовит заявку на доступ к игровым сервисам Minecraft.

Пароль вводится на сайте Microsoft. Лаунчер хранит токен обновления на компьютере только при доступном шифровании Windows.

Сервисы, к которым обращается Umbra

  • Mojang: список версий Minecraft, игровые файлы и Java.
  • Microsoft и Xbox: авторизация аккаунта.
  • Modrinth: поиск, скачивание и проверка обновлений модов.
  • GitHub: проверка и загрузка обновлений Umbra.
  • Игровые серверы: проверка доступности серверов, которые ты добавил.

Эти сервисы могут видеть IP-адрес при подключении. Umbra не добавляет к запросам игровые логи или содержимое миров.

Аналитика и реклама

В текущей версии Umbra не собирает статистику использования, не показывает рекламу и не продаёт данные.
