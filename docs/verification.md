# Проверка портфолио

Дата: 13 ноября 2026 года.

- `npm test`: 4 теста, все пройдены. Проверены обязательные поля, дополнительные данные Minecraft, кириллица и специальные символы в mailto, состав текста заявки.
- `npm run build`: production-сборка Vite 8, без ошибок и предупреждений. Созданы `dist/index.html`, SVG favicon, CSS и JavaScript. Three.js загружается отдельно от основного интерфейса.
- Playwright / Chromium: 12 сценариев, все пройдены на 1440, 1024, 768 и 375 px. Телефон и планшет проверены с сенсорным вводом; телефон — с DPR 2.
- Подтверждены отсутствие горизонтальной прокрутки, все внутренние якоря, шесть проектов и услуг, 18 превью, 2304/1152 инстанса, состояния витрины, меню телефона, доступ к подробностям, отсутствие кнопки скачивания Umbra.
- Форма: выбор услуги из строки, ошибки и перевод фокуса, поля Minecraft, кодирование mailto, Clipboard API, запрет Clipboard API и текст для ручного копирования. Проверены Escape, замыкание фокуса в окне, блокировка фона и возврат фокуса.
- С отключённым WebGL и reduced-motion сайт сохраняет контент и работающую форму; бегущая строка останавливается. Отказ загрузки шрифтов не блокирует страницу.
- Защитный таймер открывает страницу при блокировке основного JS-модуля. После принудительной потери WebGL-контекста остаются статический фон и доступная форма.
- Обычный запуск: ошибок JavaScript, компиляции шейдеров и загрузки ассетов не обнаружено. Снимки экранов просмотрены; исправлено обрезание нижней части витрины на телефоне и планшете.
- Внешние ссылки Modsmith, Axiom AI Addon, Daynote, Video Search, Cyber Bio-Site, профиль GitHub и Telegram-канал проверены: HTTP 200.

Проверки размеров выполнены в Chromium с эмуляцией. Проверка на физических телефонах и измерение устойчивых 60 FPS на разных устройствах не проводились. Форма готовит письмо и текст; фактическая отправка выполняется посетителем в его почтовой программе.
