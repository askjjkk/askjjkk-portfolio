# План реализации

Цель: готовое личное портфолио askjjkk на Vite / Three.js / GSAP / Lenis с публикацией GitHub Pages.

1. Проверить отсутствие существующей папки и репозитория, доступ к GitHub и ссылки проектов. Подготовить сборку, дизайн и workflow.
2. Реализовать семь частей страницы, шесть подробных карточек с 18 HTML/SVG-превью, три состояния витрины, услуги и этапы. Использовать факты и тексты автора.
3. Реализовать инстансированное кристаллическое поле, GLSL, туман, камерный пролёт, адаптивное качество и статический резервный фон.
4. Связать Lenis, GSAP, прелоадер с таймером 1800 мс, бегущую строку, веер, магнитные кнопки, spotlight и курсор.
5. Проверить подготовку письма и валидацию отдельными тестами. Реализовать доступные модальные окна, копирование и ручное восстановление.
6. Выполнить npm install и npm run build. Проверить браузером 375/768/1024/1440, модальные окна, якоря, консоль, reduced-motion и отказ WebGL; исправить обнаруженное.
7. Создать публичный репозиторий, включить Pages, отправить исходники, дождаться workflow и проверить опубликованную страницу и ассеты. Обновить журнал с фактическими ссылками и ограничениями.
