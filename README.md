## Что есть на сайте

- Процедурное кристаллическое поле: 2304 объекта на компьютере и 1152 на телефоне, собственные GLSL-шейдеры, туман и движение камеры при прокрутке.
- Восемь проектов. Сначала — Kktatoo, каталог отопления и «Грань», затем Modsmith, Daynote, Video Search, Umbra и Axiom AI Addon. У четырёх веб-проектов — реальные скриншоты и кнопки просмотра сайтов; у остальных — обозначенные схемы интерфейсов.
- Липкая витрина с тремя состояниями, технологии, услуги и четыре этапа работы.
- Пилотный пакет за 7 900 ₽: до пяти блоков, мобильная версия, кнопки связи, размещение и один согласованный круг правок. Материалы предоставляет клиент. Домен и хостинг оплачиваются отдельно.
- Плавная прокрутка, бегущая строка, веерные превью, подсветка карточек и магнитные кнопки. На сенсорном экране превью раскрываются по прокрутке.
- Адаптивная навигация, управление с клавиатуры, поддержка `prefers-reduced-motion` и статический фон при недоступности WebGL.

Umbra находится в разработке, каталог отопления обозначен как демонстрационный проект. Источники реальных кадров описаны в public/screenshots/SOURCES.md. Стоимость других услуг определяется после обсуждения задачи.

## Стек

Vite, Vanilla JavaScript, Three.js, GSAP / ScrollTrigger, Lenis, CSS и SVG. Внешние модели и видео не используются. Реальные скриншоты веб-проектов хранятся в public/screenshots/ и загружаются с сайта портфолио. Шрифты загружаются через Google Fonts с системными резервными вариантами; кириллический курсив — Cormorant Garamond.

## Локальный запуск

Нужен Node.js 22.12+ или актуальная LTS-версия.

```sh
npm install --no-audit --no-fund --yes
npm run dev
```

Сборка и проверка production-версии:

```sh
npm test
npm run build
npm run preview
```

Готовый сайт находится в `dist/`. Vite использует `base: '/askjjkk-portfolio/'`; локальный адрес включает этот путь.

## Проверки браузером

В отдельном терминале запустите `npm run preview -- --port 4173 --strictPort`, затем:

```sh
npx --yes playwright install chromium
npm run test:browser
```

Проверяются ширины 375, 768, 1024 и 1440 px, сцена, отсутствие горизонтальной прокрутки, якоря, карточки, модальные окна, клавиатура, подготовка письма, оба сценария копирования, reduced-motion и отказ WebGL. Отчёты и изображения сохраняются в `artifacts/`, которая исключена из Git.

При необходимости задать установленный Chromium используйте переменную окружения `PLAYWRIGHT_CHROMIUM_EXECUTABLE`. `PORTFOLIO_URL` позволяет запускать те же проверки против опубликованного сайта.

## Как работает связь

Основные кнопки связи ведут прямо в личный Telegram: https://t.me/askjjkk. Telegram-канал о проектах указан отдельно.

Форма не отправляет заявки на сервер. После заполнения она открывает почтовую программу через `mailto:` с темой и текстом письма. Письмо нужно проверить и отправить самостоятельно. Также можно скопировать заявку или рабочую почту. Если браузер запрещает копирование, появляется доступный для выделения текст.

Для услуг Minecraft форма уточняет версию игры и платформу. Данные формы не сохраняются в хранилище браузера, репозитории или аналитике. На сайте нет аналитических сервисов и токенов.

## Публикация

Workflow `.github/workflows/deploy.yml` при push в `main` устанавливает зависимости через `npm ci`, запускает тесты, собирает сайт и публикует `dist/` в GitHub Pages. Источник Pages в настройках репозитория — **GitHub Actions**. Ручной запуск доступен через `workflow_dispatch`.

При переносе в другой репозиторий обновите `base` в `vite.config.js`, canonical, Open Graph URL и ссылку сайта в README.
